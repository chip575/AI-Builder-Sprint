# 남기다 (NAMGIDA)

죽음이 구체화되는 사건을 겪었지만 아직 시간이 있는 사람이, 남기려는 마음을
대화로 정리하고 **법이 인정하는 방식으로만** 서명하며, 세션 주기와 무관하게
저장·관리·갱신하는 서비스.

- 마음 = 살아있는 유서(마음 유언, 법적 효력 없음 명시)
- 실행 = 기부·유산·자산 약정(전자서명) + 자필유언 필사 가이드
- 핵심 장치 = **법적 유효성 게이트**: 전자서명이 무효인 문서(자필증서 유언)는
  서버가 차단하고 유효한 대체 경로로 안내한다

## 실행

```bash
pnpm install
pnpm dev        # http://localhost:3000
```

**API 키 없이 전체 흐름이 동작합니다.** 외부 연동(전자서명·AI)은 기본값이
mock 모드라, 별도 설정 없이 대화 → 구조화 → 확인 → 게이트 → 문서 초안까지
바로 돌 수 있습니다. 실 연동 시에만 `.env.example`을 `.env`로 복사해 키를 채우세요.

## 검증

```bash
pnpm test        # 유닛·라우트 테스트
pnpm typecheck   # 계약(lib/contracts) 위반은 타입 에러로 잡힌다
pnpm gate:check  # 프로젝트 불변식 검사 (법률 수치 위치·보안 패턴 등)
pnpm e2e         # 발화→서명→증빙 12단계 관통 (dev 서버 띄운 뒤, 키 없이)
```

## 구조

| 위치 | 역할 |
|---|---|
| `lib/contracts/` | 입출력의 유일한 진실 — Zod 스키마. 프론트·백이 같은 것을 import |
| `lib/rules/` | 법률 수치·게이트 판정. LLM이 아니라 코드가 계산한다 |
| `app/api/` | 파이프라인 라우트 (대화→추출→확인→게이트→문서→서명→보관) |
| `spec/` | 명세. 작업 목록은 `spec/manifest.yaml` |
| `docs/decisions.md` | 설계 결정 이력 |
| `AGENTS.md` | 개발 규칙 (팀·도구 공통) |
