## 주장 한 줄

> **우리는 AI로 코드를 짠 게 아니라, AI가 코드를 짜도 무너지지 않는 구조를 짰다.**

바이브 코딩의 문제는 속도가 아니라 **검증 불가능성**이다. 생성물이 늘어날수록
사람이 따라가지 못하고, 명세와 코드가 어긋나도 아무것도 깨지지 않는다.
우리는 그 지점을 세 층으로 막았다.

## 1. SDD — 명세가 먼저, 코드가 나중

작업 순서가 `헌법 → 명세(FR) → 계획(모듈 I/O) → 절단(MVP) → 구현`이다.
이 저장소의 `spec/`이 그 산출물이고, 커밋마다 FR ID가 붙는다.

**검증 가능한 형태로 내렸다는 게 핵심이다.** 명세가 문서로만 있으면 지켜지는지
알 수 없다. 그래서 두 번 내렸다.

| 명세 층위 | 어디에 | 위반하면 |
| --- | --- | --- |
| 서사·근거 | `spec/**` (ClickUp 원본) | 사람이 읽고 판단 |
| **입출력 계약** | `lib/contracts/*.ts` (Zod) | **`tsc --noEmit` 실패** |
| 작업·소유 | `spec/manifest.yaml` | 훅이 차단 |

계약이 코드가 되는 순간 스펙 위반이 타입 에러가 된다. 이게 "AI가 만든 코드를
사람이 검증한다"는 말을 실제로 성립시키는 장치다.

## 2. 에이전트 하네스 — 모델을 난이도에 맞춘다

전부 최상위 모델로 돌리면 비싸고 느리다. 전부 저렴한 모델로 돌리면 무너진다.
그래서 **판단이 필요한 곳과 채우기만 하면 되는 곳을 분리**했다.

| 영역 | 모델 | 근거 |
| --- | --- | --- |
| 계약·게이트·룰테이블·세액공제 | Opus (초안만, 병합은 사람) | 핵심 자산. 여기 아끼면 몇 배로 토해낸다 |
| 웹훅 멱등·리컨실러·상태머신·구조화 | Sonnet | 엣지케이스 판단 필요 |
| CRUD·폼·mock·시드 | Haiku | 계약 고정 + 패턴 반복 → 판단 없음 |
| 원칙 위반 검사 | Sonnet | 체크리스트가 명확 |

에이전트 정의는 `.claude/agents/`에 있고, 각 파일 상단에 **모델 선택 이유**를
주석으로 남겼다. `contract-owner`에는 쓰기 도구를 주지 않았다 — 계약 변경은
제안만 하고 적용은 사람이 한다.

**오케스트레이터는 코드를 읽지 않는다.** `spec/manifest.yaml` 한 파일만 읽고,
워커에게는 자기 행 + 계약 파일 1개 + FR 파일 1개만 준다. 레포 전체 탐색을
금지한 것이 토큰 절감의 대부분이다.

## 3. 검증 자동화 — LLM보다 스크립트가 먼저

저렴한 모델의 실패 모드는 예측 가능하고, 대부분 코드로 잡힌다.

| 실패 유형 | 검출 | 비용 |
| --- | --- | --- |
| 계약·envelope 위반 | `tsc --noEmit` | 0 |
| 소유 경로 밖 수정 | PreToolUse 훅 (fail-closed) | 0 |
| **프롬프트에 법률 수치** | grep (`gate:check` 2·3번) | 0 |
| 개인정보 패턴 | grep (5번) | 0 |
| 폐기 용어 | grep (7번) | 0 |
| 원칙 P1~P4 의미 위반 | `constitution-gate` (Sonnet) | 여기만 |

`gate:check`가 8종을 돌고, 통과한 diff에만 LLM 검사가 붙는다.
`constitution-gate`의 첫 동작은 검사가 아니라 **차단**이다 — 보호 경로를
건드린 diff는 LLM 호출 없이 사람에게 넘긴다.

**가장 중요한 검사는 P3다.** 저렴한 모델에게 세액공제 안내 문구를 시키면
프롬프트에 16.5%를 박는다. 법률 수치가 LLM에서 나오면 그 하나로 서비스 신뢰가
끝난다. 그래서 수치는 `lib/rules/`에만 두고 LLM은 `[CALC:항목]` 토큰만 뱉는다.
프롬프트로 "숫자 만들지 마"라고 지시하는 게 아니라 **구조상 불가능하게** 했다.

## 발표 30초 버전

> AI에게 코드를 맡기면 빨라지지만, 맞는지 알 수 없어집니다.
> 저희는 명세를 두 번 내렸습니다 — 사람이 읽는 문서로 한 번, 타입체커가 읽는
> Zod 계약으로 한 번. 그래서 스펙 위반이 타입 에러가 됩니다.
> 그리고 법률 수치는 AI가 만들지 못하게 구조로 막았습니다. 프롬프트 지시가
> 아니라, 계산은 코드가 하고 AI는 토큰만 받습니다.
> 검사는 여덟 개가 자동으로 돌고, 코드로 못 잡는 원칙 위반만 AI가 봅니다.
