# 02.1.1 · M0 와이어프레임 프로토타입

> **파일 위치**: ClickUp 문서 페이지는 첨부를 지원하지 않아, 프로토타입 파일은 전용 태스크에 첨부되어 있다.  
>   
> **▶ 태스크**: [\[S0\] M0 와이어프레임 프로토타입 — 7화면 HTML](https://app.clickup.com/t/86eyegden) — 첨부된 `m0-wireframe.html`을 내려받아 브라우저로 열면 클릭 내비게이션으로 시연된다.

## 화면 흐름 (02.4 §2와 1:1)

```
S1 로그인 (auth/LoginPage)
 → S2 단일 진입 대화 — "부산에 기부하고 싶어요" → Express 감지 (chat/SessionView · FR-110·115B)
 → S3 확인·편집 — 세액공제 276,000원 산식 + 거주지 자기신고 고지 (confirm/FactSheet · FR-103·202·201)
 → S4 답례품 선택 — 30% 한도 (branch/RewardPicker · FR-203)
 → S5 문서 초안 — ESIGN_OK 게이트 배지 (doc/DraftView · FR-104·501)
 → S6 서명 진행 — 폴링 3초 + mock 완료 (doc/SignPanel · FR-502·503)
 → S7 증빙 — 해시 + 축 소개 1회 (vault/EvidenceView · FR-505·115B)
```

## 이 프로토타입이 지키는 규칙

| 규칙 | 반영 |
| ---| --- |
| 전 화면 "나중에 생각할래요" | 우하단 플로팅 버튼 (FR-101 · P4) |
| FR 태그 배지 | 각 화면 우상단 — 구현 시 명세 추적 |
| 접근성 | 본문 14px+ · 고대비 · 터치 44px+ (NFR-701, P2 기준) |
| mock 시뮬레이션 | S6 "서명 완료 시뮬레이션" = 02.4 webhook-sim의 UI 대응물 (NFR-707) |
| 고지 | 세액공제 예상 고지·법률 자문 아님·자기신고 — 전부 화면에 존재 (NFR-706) |

## 구현 이관 규칙

*   이 HTML의 화면 분할이 곧 `app/` 라우트 분할이다 — S2=`app/chat`, S3=`app/confirm`, S4=`app/branch/rewards`, S5·S6=`app/doc`, S7=`app/vault`
*   CSS 변수(`--accent` 등)는 Tailwind 테마 토큰으로 치환
*   mock 버튼의 onclick은 실제 `POST dev/webhook-sim` 호출로 교체
*   **디자인 수정은 이 파일이 아니라 코드에서** — 프로토타입은 M0 착수 후 스냅샷으로 동결, 이후 변경은 코드가 진실

## 후속

*   M1 (대시보드 · 시간압축 · 종이약정 옮기기) 와이어프레임 — 태스크 todo에 등록됨
*   M2 (축 대화 · 필사 가이드 · 숙려 화면) 와이어프레임 — M0 팀 리뷰 후 제작
