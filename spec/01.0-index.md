## 1\. 대상 한 문장

> 죽음이 구체화되는 사건을 겪었지만 아직 시간이 있는 사람에게, 남기려는 결심이 절차의 마찰과 기록되지 않는 변심으로 사라지지 않도록, 대화로 정리하고 **법이 인정하는 방식으로만** 서명하며 세션 주기와 무관하게 저장·관리·갱신함으로써 — **마음은 살아있는 유서로, 실행은 유효한 약정으로** 남기게 한다.

| 페르소나 | 한 줄 |
| ---| --- |
| P1 사별 겪은 자녀 (40~50대) | 본인의 축을 일찍 시작. 초대 흐름은 확산 방향 |
| P2 정리 시작한 시니어 (60~70대) | 대표 형상 — 축·가지·생애주기 전부 경험 |
| P3 고향 기부자 | 가지 단독 · Express 진입 (사건 정의 밖 정상 수용) |
| P4 기부처 담당자 | 도입 주체 · 대시보드 |

호스피스 = 대표 아님(이용 ~22%·평균 15일 — 차별점 작동 시간 없음), **확산 시나리오**로만.
