# 01.4 · NFR — 비기능 요구사항

> 뒷부분에 **추적성 매트릭스**와 **스펙 변경 규칙**이 있다. 범위 축소 시 FR을 삭제하지 말고 `DEFERRED` 처리한다.
* * *

## NFR-700 · 비기능 요구사항

| ID | 요구 | 수락 기준 |
| ---| ---| --- |
| NFR-701 | 접근성 — 대표 형상 P2(60~70대)를 기준으로 설계한다. 나이가 타겟 조건은 아니지만 대표 사용자의 연령대가 설계 요구를 정한다 | 본문 최소 18px, 명도 대비 4.5:1 이상, 터치 타깃 44px 이상, 키보드만으로 전체 흐름 탐색 가능 |
| NFR-702 | 응답성 | LLM 응답 스트리밍. 첫 토큰까지 2초 이내. 문서 생성은 진행 표시 필수 |
| NFR-703 | 개인정보 | 주민등록번호·계좌번호 원문 저장 금지(마스킹 표시만). 업로드 문서는 비공개 저장소 + 서명된 임시 URL로만 접근 |
| NFR-704 | 감사 로그 | 모든 상태 전이를 `actor / action / timestamp / prevState / nextState`로 기록. 사용자 삭제 불가 |
| NFR-705 | 오류 처리 | 외부 API 실패 시 기술 오류 코드 대신 다음에 할 행동을 제시한다 |
| NFR-706 | 고지 | 모든 문서 화면에 "법률 자문이 아니며 참고용입니다" 고지 상시 노출 |
| NFR-707 | 재실행성 | `pnpm install && pnpm dev` 로 실행. 외부 키 없이 목(mock) 모드로 전 흐름 시연 가능 ← 예선 에이전트 3회 독립 실행 대비 |
| NFR-708 | 정서적 안전 | 죽음·상실 관련 대화에서 재촉·긴급성 조성 금지. 중단 선택지 상시 제공. 위기 신호 감지 시 상담 자원 안내 |
| NFR-709 | 관측성 | 파이프라인 6단계 각각의 성공/실패/소요시간을 로깅. 데모에서 지표로 보여줄 수 있어야 한다 |

## 추적성 매트릭스 (Traceability) — MVP 단위

> ⚠️ 기존 Phase 기반 매트릭스를 **03.0 MVP 기준으로 교체한다.**

| FR 그룹 | MVP | 핵심 컴포넌트 |
| ---| ---| --- |
| FR-100 (공통 파이프라인) | M0 | Intent Engine, Solar 구조화, Validity Gate |
| FR-200 (기부·답례품·세액공제) | M0+M1 | Donation Rules, Template Engine, Obligation |
| FR-300 (유언·편지·유산기부) | M2 | Will Composer, Handwriting Guide, Express 숙려 |
| FR-400 (자산·Custodian) | M4 (여력) | Document Parse+IE, Inventory, Custodian 약정 |
| FR-500 (전자서명·CLM) | M0+M1 | Signature Orchestrator, Webhook, Reconciler |
| FR-550 (의사 이력) | M3 | Intent Ledger, Attestation, Hash Chain |
| FR-600 (대시보드) | M1 | Admin Dashboard (최소: 상태별+증빙) |
| FR-110~115 (축·가지) | M2 | Question Bank, Coverage, HeartWill, Branch Detect |
| NFR-700 | 전 층 | 접근성·보안은 M0부터, 관측성·정서적 안전은 M2부터 |
| NFR-710~715 (보안) | M0부터 | 마스킹·보안지침은 첫 날, Custodian 부분열람은 M4 |

**연결이 없는 FR은 구현되지 않은 것으로 간주한다.** 범위 축소 시 FR을 삭제하지 말고 `DEFERRED`로 표시한다.
* * *

## 스펙 변경 규칙

1. 구현 중 스펙과 다르게 만들고 싶어지면 **코드를 고치기 전에 이 문서를 고친다.** (헌법: 명세가 소스)
2. 변경 시 해당 FR의 수락 기준을 함께 갱신한다. 수락 기준 없는 FR은 검증 불가 → 무효.
3. 시간이 부족해 범위를 줄일 때는 FR을 **삭제하지 말고** 상태를 `DEFERRED`로 표시한다. 발표 때 "의도적으로 남긴 것"과 "못 한 것"을 구분해 말할 수 있어야 한다.
